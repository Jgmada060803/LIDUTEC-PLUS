# Ficha de Moldagem

O layout `moldagem_v1` organiza grupos em blocos que podem ocupar duas
colunas no desktop e uma coluna no celular. Parâmetros exibem referência,
nome, unidade, valor nominal, mínimo, alvo, máximo e observação.

O seed MS0013 cria o documento `FTMO-0013`, revisão 22, emitido em
19/06/2026. Valores não legíveis não são inferidos; grupos sem informação
confirmada permanecem preparados para cadastros posteriores.

Para testar, abra:

`pages/produtos/moldagem.html?produto=ID_DO_MS0013`
